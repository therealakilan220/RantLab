RantLab: 24-Hour Task Sheet

Team Fantastic 4, Open Innovation track. Everything runs on free, local tools with no paid API. Rename the columns to your real names.

Ticks and names are saved in this browser only. Agree on one person to keep the master copy, or check in at each checkpoint.

Rules for a 24-hour build

Must ship (MVP)

  1. Record or type a rant
  2. Transcribe locally
  3. Three fixes with owner, cost and timeframe
  4. Shareable card
If this works on a phone at H16, you are safe.

Cut in this order

  1. Rough visual concept image
  2. Recurring-issue ranking
  3. Board page polish
  4. Download card as PNG
  5. Board page entirely (show clusters in a terminal or slide instead)

Free stack

  • Ollama with qwen2.5:3b (LLM)
  • faster-whisper (speech to text)
  • sentence-transformers MiniLM (clustering)
  • FastAPI, SQLite, Next.js, Tailwind
  • GitHub, OBS, html-to-image
  • Cloudflare Tunnel or ngrok free plan (HTTPS link so phones can use the mic)

Risks and fallbacks

  • Laptop too slow for 3B: drop to qwen2.5:1.5b or use whisper tiny. Decide by H1.
  • Model returns bad JSON: validate and retry once, keep a canned example card for the demo.
  • Mic blocked off localhost: needs HTTPS, so set up the tunnel by H6.
  • Venue Wi-Fi fails: phone hotspot, plus the backup video.
  • Optional fallback: a free-tier hosted model (Gemini or Groq), rate-limited and needs a key. Check current limits first and keep it off by default.
